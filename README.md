# 🚗 Car Price Prediction using Machine Learning

## CodeAlpha Data Science Internship — Task 3

### 📌 Project Overview

This project focuses on predicting car prices using machine learning regression techniques.

The model uses vehicle characteristics such as brand, model, manufacturing year, engine size, fuel type, transmission, mileage, number of doors, and owner count to predict the price of a car.

## 🎯 Objective

The main objective is to develop a machine learning model that can predict car prices based on different vehicle features.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 📊 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Data Preprocessing
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Car Price Prediction

## 🤖 Machine Learning Models

### Linear Regression
Used as a baseline regression model for predicting car prices.

### Random Forest Regression
An ensemble learning algorithm used to improve prediction performance by combining multiple decision trees.

## 📈 Evaluation Metrics

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🔍 Exploratory Data Analysis

The project includes visualizations showing:

- Distribution of car prices
- Car Price vs Mileage
- Car Price vs Manufacturing Year
- Average Price by Fuel Type
- Average Price by Transmission
- Actual vs Predicted Prices
- Prediction Error Distribution

## 🚗 Final Prediction

The trained model is used to predict the price of a new car based on its vehicle characteristics.
